# Scene 02 — The Problem & The Number
**Ad:** Segment 5 — The Classic Lit Aspirant
**Timestamp:** 0:05–0:14
**Duration:** 9 seconds
**Format:** 9:16 vertical
**Energy:** Gently honest → suddenly expansive

---

## Purpose

Acknowledge the real reason they haven't read these books — not laziness, not lack of
interest, just life. Then immediately pivot to the scale of what's available — for free.
The "70,000 books. Free." moment should feel like a door swinging open.

---

## Visual Description

**Part A (0:05–0:08) — The Busy Life:**

A different environment now — busy, modern. Person at a kitchen table or home desk,
clearly occupied: laptop open, coffee going cold, phone buzzing beside them.
On the table, visible but untouched: the same kind of hardcover book from Scene 01.
It's been there a while. They glance at it for just a moment — a small flicker of
intention — then back to the screen.

Camera: Medium shot. Natural, slightly handheld. Documentary feel.
This is a real moment, not a posed one.

**Part B (0:08–0:11) — The shift:**

Same person. But now they're standing at the kitchen sink doing dishes,
or folding laundry — AirPods in. The same book is not in sight.
Their expression is different: calm, thoughtful, engaged.
They're listening to it now, during the time that was already taken.

Camera: Medium wide. Static or very slow pull in.

**Part C (0:11–0:14) — The Number:**

Full-screen text animation on warm cream/beige background.
No photography. Pure typography.

```
70,000 books.
```
*(pause 0.8s)*
```
Free.
```
*(pause 0.8s)*
```
Starting today.
```

Each line appears cleanly, large, centered. Space Grotesk Bold.
The word "Free." is slightly larger and in Loud Blue (`#2EC7F6`).
"Starting today." is regular weight — an invitation, not a demand.
