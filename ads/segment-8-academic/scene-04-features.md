# Scene 04 — Feature List
**Ad:** Segment 8 — The Academic
**Timestamp:** 0:32–0:40
**Duration:** 8 seconds
**Format:** 16:9 horizontal
**Energy:** Clean, factual, complete — the specification sheet for an evidence-based buyer

---

## Purpose

Academics evaluate tools by their specs before their aesthetics. Give them the
complete feature set clearly. No marketing language — just the list.
This is the product's specification moment.

---

## Visual Description

**Clean white or near-white background. Full-screen feature list.**

Five items appear sequentially (one every ~1.2 seconds), each sliding in from the left:

```
✓  Import any PDF or EPUB
✓  Word-by-word text highlighting
✓  Variable speed: 0.3× to 3×
✓  100% offline — no internet required
✓  Zero data collection — not even crash reports
```

**Typography:** Space Grotesk Regular. Dark text on white. Clean, clinical, honest.
No icons beyond the checkmark. No color accent except the cyan (#2EC7F6) checkmarks.

The list feels like a requirements checklist — which is exactly how this person thinks.

---

## Voice-Over

*(Speaking simultaneously as each item appears)*
*"Import any PDF. Word-by-word highlighting. Full speed control.*
*A hundred percent offline. Zero data collected."*

Not selling. Confirming.
